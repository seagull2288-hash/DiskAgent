# NX12 精确两案例智能体交付 v3.0

交付目录为nx_case_agent，必须完整复制其中assets、examples及程序文件。资产已经随模块内置；接收方无需原始桌面路径或以前的对话，但不能删除assets目录。

本版默认精确生成参考几何。二维为完整控制网和原始节点的关联样条重建，1面14边，支持X1～X5和Y1～Y4。三维保留原始new160.x_t的全部台阶、真实叶片、叶根过渡和裁剪边界，1实体44面122边，不再使用菱形叶片或猜测轮毂轮廓。

三维当前采用精确B-rep案例实例化加NX原生轴向/径向整体缩放，仅hub_length和rim_radius可独立修改，其余尺寸联动。原作者的完整草图/回转/放样特征历史尚未恢复，叶型、扭转、局部圆角和独立薄盘厚度不能单独优化。界面和API都明确报告这一范围，不能把几何精确复制当作完整特征级参数化。

配置本机NX12与许可后运行：
```powershell
$env:NX_AGENT_NXBIN='<本机NX12目录>\NXBIN'
python -X utf8 nx_case_agent/agent.py web --port 8771
```
打开 http://127.0.0.1:8771 。当前分支已接入DiskAgent，重启后访问/case-modeling，或点击自动建模页面中的“两案例建模智能体”。

移植到兼容的其他DiskAgent版本，可使用交付包内diskagent_integration.patch。先运行git apply --check，通过后再应用；若冲突，按补丁中的路由、入口和MCP包装手动集成。本模块的独立Python/Web/MCP接口不依赖该补丁。

每次生成都检查完整拓扑、NX内核有效性、真实参数更新、保存重开，以及与完整参考几何的双向边界/裁剪面内采样偏差。阈值为0.001毫米，面积/体积差阈值为0.001 mm²/mm³；记录会注明采样验证不构成连续曲面全域误差上界证明。失败时报告错误，不回退到简化几何。精确模式的三维案例比简化模型耗时长，本机本轮约3分钟。

原始二维描述和上一轮带Markdown加粗的三维描述均经真实MCP→NX测试。三维6项显式尺寸识别成功，二维10项、三维2项独立参数更新与恢复均通过。详细偏差记录在acceptance_mcp.json及acceptance_2d.json、acceptance_3d.json，示例PRT在examples目录。相关规划、工作台接口及原建模回归测试共41项通过。

详细配置、参数耦合、精度规则与维护模块划分见nx_case_agent/README.md。
