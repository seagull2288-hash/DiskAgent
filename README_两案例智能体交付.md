# NX12 两案例智能体交付

交付目录：`nx_case_agent/`。仅复制此目录即可独立使用，不依赖DiskAgent和此前对话，也不需要原始模型文件。

本分支已接入DiskAgent：重新启动工作台，进入 `/modeling`，点击“两案例建模智能体”，或直接访问 `/case-modeling`。

如果使用交付压缩包移植到其他DiskAgent副本，先复制 `nx_case_agent` 文件夹到其项目根目录。包内 `diskagent_integration.patch` 提供工作台路由、页面入口和原NX MCP服务的集成改动；在兼容的项目基线上先运行 `git apply --check diskagent_integration.patch`，通过后运行 `git apply diskagent_integration.patch`。若检查提示冲突，可按补丁中的少量路由改动手动集成；Python与独立MCP接口不依赖该补丁。

接收方先配置本机NX12路径和许可，然后运行 `python nx_case_agent/agent.py web`，打开 http://127.0.0.1:8771 。详细说明和MCP配置见 `nx_case_agent/README.md`。

可以输入：

> 做一个内外端厚、中间薄、上下对称的二维轮盘截面，主要尺寸参数化。

> 做一个带一片叶片的三维轮盘局部，包含轮毂、薄盘、外缘和向外伸出的渐缩叶片，主要尺寸参数化。

智能体从案例配方补全缺失尺寸，在预览里展示，并允许调整。也可由优化智能体通过结构化parameters对象提交候选值。

2026-11-19在NX12实测，两类模型均生成并重新打开通过；二维10个命名尺寸、三维13个命名尺寸已逐个扰动测试，更新错误均为0。真实stdio MCP到NX生成链通过。相关37项规划、网页集成与原有建模测试通过。

当前学习的是两种结构的可执行配方，没有训练大模型权重。二维采用圆弧近似过渡，三维采用简化回转盘体和菱形截面叶片，未建立叶根圆角；不承诺精确复刻，也不表示已完成气动设计或有限元优化接通。
